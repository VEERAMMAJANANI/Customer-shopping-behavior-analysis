# Data Analytics Project

## Overview

This project demonstrates an end-to-end Data Analytics workflow using Python, SQL, and Power BI. The objective is to transform raw data into meaningful insights through data cleaning, exploratory data analysis (EDA), SQL-based querying, and interactive dashboard creation. The final findings are presented through a business report and a presentation created using Gamma.

---

The dataset contains business-related data used for analysis and visualization.

### Dataset Features

* Multiple records with structured information
* Numerical and categorical attributes
* Suitable for data cleaning, analysis, and reporting

### Data Source

* CSV/Excel file
* Public dataset or business dataset

## Project Steps

### 1. Data Loading

* Imported dataset into Python using Pandas.
* Examined dataset structure and data types.

### 2. Data Cleaning

* Handled missing values.
* Removed duplicate records.
* Corrected inconsistent data formats.
* Standardized column names.

### 3. Exploratory Data Analysis (EDA)

* Generated summary statistics.
* Identified trends and patterns.
* Analyzed distributions and relationships.
* Created visualizations for better understanding.

### 4. SQL Analysis

* Loaded cleaned data into a database.
* Executed SQL queries for business insights.
* Used filtering, grouping, aggregation, joins, and ranking functions.

### 5. Dashboard Development

* Connected Power BI to the processed dataset.
* Built interactive dashboards and reports.
* Added filters, KPIs, and visual charts.

### 6. Reporting & Presentation

* Documented findings in a business report.
* Created a presentation using Gamma.
* Highlighted key insights and recommendations.

## How to Run

### Step 1: Clone the Repository

```bash
git clone <repository-link>
```

### Step 2: Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn
```

### Step 3: Run Python Analysis

```bash
jupyter notebook
```

Open the notebook and execute all cells.

### Step 4: Execute SQL Queries

* Import the dataset into MySQL/PostgreSQL/SQL Server.
* Run the queries provided in the SQL folder.

### Step 5: Open Power BI Dashboard

* Open the `.pbix` file in Power BI Desktop.
* Refresh the dataset connection if required.
